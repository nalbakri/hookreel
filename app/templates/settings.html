Show setup guide ▼
How to set up Telegram Cinema
  1. Create a private Telegram group.
  2. Add your HookReel bot to the group as admin.
  3. Tap the group name at the top.
  4. Tap More -> Start Live Stream -> Stream with third-party app.
  5. Copy the Server URL and Stream Key shown.
  6. Paste them into the fields above and save.

IMPORTANT: Each time you want to stream, you must first tap Start Streaming in the Telegram group, then ask your agent to stream the movie. The bot will remind you when to do this.

Remote access via Tailscale
  1. Install Tailscale on your server:
    curl -fsSL https://tailscale.com/install.sh | sh
    sudo tailscale up
  2. Install Tailscale on your phone or laptop from tailscale.com/download
  3. Sign in to the same Tailscale account on both devices.
  4. Access HookReel at:
    http://[your-tailscale-ip]:8765

No port forwarding or firewall changes needed.
